# Evidence index

- `hardware/` — hardware report/spec screenshot and hostname evidence.
- `load/`, `stress/`, `spike/` — each has a screenshot showing the test tool and backend resource monitor in the same frame.
- `issues/` — screenshots and URLs for genuine GitHub Issues, if any.
- `video/` — a text file with the unlisted YouTube URL and timestamps.

Use meaningful filenames such as `2026-08-11_load_jmeter-and-activity-monitor.png`.
